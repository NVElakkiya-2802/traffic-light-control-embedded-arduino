# traffic-light-control-embedded-arduino
Microcontroller based Traffic Light Controller using Embedded C and LEDs

# Description
This project implements a microcontroller-based traffic light controller using Embedded C.  
It controls Red, Yellow, and Green LEDs with programmed delays to simulate real traffic signals.

# Components
- Arduino / Microcontroller
- LEDs (Red, Yellow, Green)
- Resistors
- Breadboard

# Features
- Automatic signal switching
- Configurable timing
- Sequential traffic control

# Tools Used
- Embedded C
- Tinkercad Circuits (simulation)
